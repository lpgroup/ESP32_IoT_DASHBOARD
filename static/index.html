ESP32 • Ambiente 01

Uma fonte, uma visão completa do ambiente.

Como os dados chegam até aqui

  1. 01 Sensor IoT

    O ESP32 registra temperatura e umidade e envia as medições para sua planilha.

  2. 02 Google Sheets

    A planilha publicada armazena o histórico e disponibiliza os dados em CSV.

  3. 03 Seu dashboard

    A API Python valida as leituras. O painel consulta atualizações automaticamente enquanto estiver aberto.

A atualização depende do envio do ESP32 e do tempo de publicação do Google Sheets. A frequência de consulta não é a frequência de medição.
